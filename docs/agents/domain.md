# Domain Docs

Read the root `GLOSSARY.md` and relevant decisions under `docs/adr/`
before exploring or changing the Garmin archive and sync domain. If
`docs/adr/` does not exist, proceed without it.

This repo uses one shared domain context: the root glossary covers the
Garmin archive and its Notion sync. Use its terms in designs, tickets,
tests, and implementation notes.

Create a glossary entry only when a term is resolved. Create an ADR only
when a consequential, surprising trade-off needs to be recorded. The
`domain-modeling` skill owns those updates.
