# Triage Labels

The skills speak in terms of five canonical triage roles. This file maps
those roles to the labels used in Vikunja.

| Role | Vikunja label | Meaning |
| ---- | ------------- | ------- |
| `needs-triage` | `needs-triage` | Maintainer needs to evaluate this issue |
| `needs-info` | `needs-info` | Waiting on the reporter for more information |
| `ready-for-agent` | `ready-for-agent` | Fully specified, ready for an agent |
| `ready-for-human` | `ready-for-human` | Requires human implementation |
| `wontfix` | `wontfix` | Will not be actioned |

When a skill mentions a triage role, use the corresponding Vikunja label.
